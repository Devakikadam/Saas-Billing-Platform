# SaaS Billing Platform

A full-stack SaaS Billing Platform developed using React, Flask, and MongoDB.

## Features
- User Registration & Login
- Subscription Plans
- Purchase Subscription
- My Subscription
- Invoice Management
- Admin Dashboard
- PDF Generation

## Technologies Used
- React
- Flask
- MongoDB
- Vite
