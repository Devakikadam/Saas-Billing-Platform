# SaaS Billing Platform

A full-stack SaaS Billing Platform developed using React, Flask, and MongoDB.

## Features
- User Registration & Login
- Subscription Plans
- Purchase Subscription
- My Subscription
- Invoice Management
- PDF Invoice Download
- Admin Dashboard
- Admin Subscription Management
- Cancel Subscription
- MongoDB Integration

## Tech Stack
Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Flask
- Python

Database:
- MongoDB

## Project Modules
1. Authentication
2. Subscription Management
3. Invoice Management
4. Admin Panel
5. PDF Generation
